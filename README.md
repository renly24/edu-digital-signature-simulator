# 電子署名のしくみ（教育用）

デジタル文書の改ざんやなりすましを防ぐ **電子署名** のしくみを、ハッシュ関数・電子証明書・鍵を自分で動かしながら学ぶ教育用の Web アプリです。

## 学べること

教科書（情報 I「安全な通信」）の電子署名の範囲を、全5章・12枚のスライドで、自分で操作しながら学びます。ほとんどのスライドに「🎯 やってみよう」（操作の課題）があり、クリアすると次のスライドへ進めます。

1. **電子署名とは**：悪い人になって文書を改ざん・なりすましし、受信者には見分けがつかないことを体験。電子署名（デジタル署名）は本人確認と改ざん防止に使われること
2. **ハッシュ関数**：同じデータなら同じハッシュ値、1文字でも違えばまったく違うハッシュ値になること、ハッシュ値から元のデータを推測するのは困難なこと
3. **認証局と電子証明書**：送信者が鍵のペアを作り、公開鍵を認証局に届け出て電子証明書を発行してもらう（①②）
4. **電子署名のしくみ**：ハッシュ値を求めて秘密鍵で暗号化し電子署名を作る（③④）、3つを送る（⑤）、受信者が電子証明書を確かめ、公開鍵で電子署名を復号したハッシュ値 A と文書から求めたハッシュ値 B を比べる（⑥〜⑨）。改ざん・なりすましの場合に一致しないこと
5. **まとめ**：送信者・認証局・受信者の役割の仕分け、作成と検証に使う鍵の組み合わせ、8問のまとめテスト（採点・見直し付き）

### さわって確かめる（いろいろな操作）

| 操作 | スライド |
| --- | --- |
| **ダブルクリック** | 文書の金額や差出人を書きかえる（改ざん・なりすまし）／鍵を作る機械で鍵のペアを作る |
| **キーボード入力** | 文書を書きかえて、ハッシュ値の変わり方を見る |
| **マウスホイール** | ハッシュ値から元のデータを当てようと、言葉を次々に試す |
| **ドラッグ** | 公開鍵を認証局へ届け出る／文書をハッシュ関数へ、秘密鍵をハッシュ値へ重ねて電子署名を作る／電子証明書・電子署名・文書の札を送る／公開鍵を電子署名へ、文書をハッシュ関数へ重ねて確かめる／役割を仕分ける／作成と検証に使う鍵を選ぶ |
| **クリック** | 認証局で電子証明書を確かめる／改ざん・なりすましのタブを切りかえる |

ドラッグの操作は、タップで選んでからタップで置く方法でもできます（スマホ・タブレット向け）。

### 問題の種類

- **予想問題**：操作の前に「どうなると思う？」と考える問題。答えるまで次のスライドへ進めません。正解の位置は問題ごとにばらばらです
- **体験問題**：電子証明書を発行してもらう、電子署名を作る・確かめる、役割を仕分ける、鍵を選ぶなど、自分で操作する問題
- **確認問題**：最後のまとめテスト。まとめテストの結果画面はスクリーンショットで提出する想定です（結果はサーバに保存されません）

パワーポイントのスライドのように、画面下の「前へ」「次へ」ボタンやスライドのクリック・タップで1枚ずつ進めます（← → ・スペースキーでも操作できます。問題や「やってみよう」のあるスライドではクリックで進みません）。

## 開発

```bash
npm ci
npm run dev    # http://localhost:3000
npm run build  # out/ に静的ファイルを出力
```

`main` ブランチにプッシュすると、GitHub Actions がビルドして次の2か所に公開します。

- GitHub Pages: https://renly24.github.io/edu-digital-signature-simulator/ （Settings → Pages で Source を「GitHub Actions」にしておく）
- FTP サーバー: http://e.gmobb.jp/omaesensei/digital/edu-digital-signature-simulator/ （`.github/workflows/deploy-ftp.yml`）

FTP へのアップロードには、リポジトリの Settings → Secrets and variables → Actions に `FTP_HOST`・`FTP_USER`・`FTP_PASS` の3つを登録しておく必要があります。
